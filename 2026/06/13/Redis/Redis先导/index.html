Redis先导

发表于2026-06-13|更新于2026-06-22|Redis

因为黑马课程的Reids是在Linux中使用的，所以我们需要提前执行以下操作：虚拟机VMware的安装，Linux系统的配置，FinalShell的下载与配置，Redis与其桌面客户端的安装指导,便于后续黑马Redis从入门到实战的课程学习。

常见问题

按照黑马Linux教学视频中的操作，在输入密码的时候可能显示didnt work可以试着在安装的时候创建用户，就是在等待时间最长的页面。如果上面显示Connection failed就重启一下电脑试试。

实在不行的话就在创建虚拟机的时候选择“经典”安装，再选择“稍后配置iso文件”，创建好后在虚拟机配置中配置iso文件其他不用动，启动虚拟机后选择“install centos”，后会进入“安装信息摘要”，如果想要图形化界面，就在软件安装中选择“带GUI的服务器”，选择“最小安装”的话也能学习此课程，后配置安装目的，选择“自定义”，点击“左上角完成”后点击“点击这里自动创建他们”，下面选择“标准分区”然后又会跳转到一个页面配置“/”的期望容量为20GIB。注意安装摘要中带有黄色感叹号的就说明这是必须完成的安装操作。最后返回安装摘要点击“下一步”创建用户就可以开启虚拟机了。

也可以直接把安装摘要喂给AI根据自己的需要让他推荐怎么配置。

使用finalShell链接虚拟机的时候，终端输入ip addr，en33如果不显示inet，就在右上角打开有线连接。

在执行yum时，若无法使用。（因为CentOS-7官方已经停止维护了，所以得换源）需要更换镜像源，可以在B站观看莲城的老李的“CentOS更换yum源”的视频，更换的是阿里云的yum源，记得把有线连接打开。

推拽redis压缩文件：先在虚拟机中cd到文件目录，再使用fianllshell的在终端的右上角有一个向上的箭头点一下就可以上传文件了。

修改redis.conf配置文件 vi 进去后是只读状态按Insert就进入编辑模式，ESC退出编辑模式，再只读状态下我们可以保存(输入:wq)，也可以搜索(/搜索内容)。

配置好后就可以基于配置文件后台启动了，kill是杀死reids进程，用来关闭redis。

Redis的启动方式：

  • 默认启动
  • 指定配置文件启动
  • 开机自启

此课程我们使用开机自启，配置好后以下是一些常见指令:

网络连接及修改后的注意事项。

如果遇到虚拟机网络连接不上的情况可以去B站搜雪之起飞2026的教程。配置好en33的inet也会改变，在虚拟机输入ip addr查看，在finalshell上重新建立连接。resp也要重新建立连接。代码的配置文件中的Redis配置中的host也要改成inet的ip。这里注意一下，数据库长期不连接的话他会断开连接。我们在idea右边的MySQL工具栏中刷新一下就行了。
