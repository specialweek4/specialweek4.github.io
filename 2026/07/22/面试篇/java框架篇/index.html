spring 框架中的bean是线程安全的吗？

这里解释以下什么是无状态，无状态就是不能被修改，spring bean并没有可变的状态，因为bean是单例的，注入的都是无状态的对象（一个类型的bean只有一个）。所以某种程度上Spring的单例bean是线程安全的。

如果在bean中定义了可修改的成员变量的话，是要考虑线程安全问题的。可以使用bean多例（使用@Scope注解修改成多例）和加锁来解决。

介绍一下AOP

Spring AOP是面向切面编程，通过动态代理在不修改源码的情况下，给目标方法添加额外功能。核心概念有目标对象，即被增强的原始对象；连接点，是程序执行中的特定点，比如方法执行；切入点，是要增强的连接点，通过表达式定义；通知，是增强的逻辑，有前置、后置、环绕、异常、最终通知；切面，是切入点和通知的组合；织入，是将切面应用到目标对象生成代理对象的过程。

在Spring AOP中，代理是实现AOP的方式，当目标对象实现接口时，默认用JDK动态代理，通过接口生成代理类；如果没有实现接口，就用CGLIB代理，通过继承目标类生成代理子类。
