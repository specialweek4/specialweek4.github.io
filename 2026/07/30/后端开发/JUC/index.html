线程和进程的区别

一个进程包含一到多个线程

  • 进程是正在运行程序的实例，进程中包含了线程，每个线程执行不同的任务
  • 不同的进程使用不同的内存空间，在当前进程下的线程可以共享内存空间
  • 线程更加轻量

并发和并行的区别

  • 并发：多个事件在同一时间间隔内发生
  • 并行：多个事件在同一时刻发生

创建线程的方式有哪些？

1.继承Thread类

2.实现runnable

3.实现Callable接口

4.使用线程池来创建线程

Runnable 和 Callable的区别

  • Runnable 接口的run方法没有返回值
  • Callable 接口的call（）方法允许抛出异常，而Runnable接口的Run（）方法只能在内部笑话异常，不能继续上上抛

run方法和statr方法的区别

  • start方法是开启一个线程.一个线程对象只能调用一次start方法。
  • run（）封装了要被线程执行的代码，可以被调用多次。

线程包含了哪些状态，状态之间如何转换？

Java 线程在 java.lang.Thread.State 中定义了 6 种状态，其转换关系如下图所示：

    [*] --> NEW : 实例化 Thread 对象

    NEW --> RUNNABLE : Thread.start()

        direction LR
        READY --> RUNNING : 系统调度 / 获得CPU时间片
        RUNNING --> READY : Thread.yield() / 时间片用完

    RUNNABLE --> WAITING : Object.wait()<br/>Thread.join()<br/>LockSupport.park()
    WAITING --> RUNNABLE : Object.notify() / notifyAll()<br/>LockSupport.unpark()

    RUNNABLE --> TIMED_WAITING : Thread.sleep(long)<br/>Object.wait(long)<br/>Thread.join(long)<br/>LockSupport.parkNanos()<br/>LockSupport.parkUntil()
    TIMED_WAITING --> RUNNABLE : Object.notify() / notifyAll()<br/>LockSupport.unpark()<br/>超时时间到

    RUNNABLE --> BLOCKED : 等待进入 synchronized 方法/块<br/>（未竞争到锁）
    BLOCKED --> RUNNABLE : 成功获取到锁

    RUNNABLE --> TERMINATED : run() 方法执行完毕
    TERMINATED --> [*]
状态 说明
NEW 线程实例已创建，但尚未调用 start()
RUNNABLE 可运行状态，包含 READY（就绪）和 RUNNING（运行中），由系统调度切换
WAITING 无限期等待，直到被其他线程显式唤醒
TIMED_WAITING 超时等待，等待指定时间后自动返回，或被提前唤醒
BLOCKED 阻塞状态，等待获取 synchronized 锁
TERMINATED 线程执行完毕，生命周期结束

线程包含哪些状态

新建（NEW），可运行（RUNNABLE），阻塞（BLOCKED）, 等待（WAITING），时间等待，终止。

线程状态之间是如何变化的

  • 创建线程对象是新建状态。
  • 调用了start()方法转变为可执行状态
  • 线程获取到了CPU的执行权，执行结束时终止状态
  • 在可执行状态的过程中，如果没有获取CPU的执行权，可能会切换其他状态
    • 如果没有获取锁进入阻塞状态，获得锁在切换为可执行状态
    • 如果线程调用了wait()方法进入等待状态，其他线程调用notify()唤醒后可切换为可执行状态
    • 如果线程调用了sleep(50)方法，进入计时等待状态，倒时间后可切换为可执行状态

新建T1、T2、T3线程，如何保证他们按顺序执行？

额可以使用join()方法，让一个线程等待另一个先成完成后再执行。

notify和notifyAll的区别

  • notify: 唤醒所有wait线程
  • notify：只随机唤醒一个wait线程。

wait和sleep方法的不同

Thread.sleep() 和 Object.wait() 的区别：

  • 所属不同：sleep 是 Thread 的静态方法，可以在任何地方直接通过 Thread.sleep() 调用，不需要对象实例；wait 是 Object 的实例方法，需要对象实例。
  • 锁的释放：Thread.sleep()在调用的时候,让线程暂停执行，但不会释放持有的对象锁，直到synchronized中的方法执行完才会释放锁，也就是说，在sleep期间，其他线程无法获得该线程持有的锁；Object.wait() 调用该方法的时候，线程会释放锁，进入等待状态，直到另一个线程调用 notify() 或 notifyAll() 唤醒它。
  • 使用条件：sleep 可以在任何地方调用，不需要事先获取锁；wait 必须在 synchronized 代码块或方法中调用，否则抛出 IllegalMonitorStateException。
  • 唤醒机制：sleep 会在时间结束后自动恢复执行，等待 CPU 调度；wait 需要其他线程调用 notify() 或 notifyAll() 来唤醒等待的线程。
