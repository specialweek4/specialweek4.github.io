Floyd算法

迪杰斯特拉算法是求某个点到某点的最短路径，而弗洛伊德算法是求任意两点之间的最短路径。

这个算法需要到邻接矩阵

弗洛伊德算法简单来说就是依次将每个点做为 中间点 去做更新

两个表 D 记录的是最短路径，path 记录的是终点的前一个点（自己到自己或者是，没有的都填-1），D(-1) 表示的最初的状态。D(-1) 和 邻接矩阵是一样的(两点直达)。

接下来依次将每个点作为中间点去更新，首先是以 0 作为中间点去更新

注意：当两点新路径的长度大于旧路径长度的时候我们不更新它在 D 表的数据。

以 0 为中间点就表示以 0 为终点或起点的我们更新，并且自己到自己的为 0 它本身就是最小的我们也不更新。我们照搬上面的，在Path对应的点也照搬。

1 -> 2 ,以 0 做中间点的话 1 -> 0 -> 2 = 23，比 1 -> 2 大我们就不更新还为 4 ，对应的Path也不更新。

凑合着看吧.
