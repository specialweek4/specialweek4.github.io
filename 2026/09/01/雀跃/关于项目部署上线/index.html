关于项目部署上线

发表于2026-09-01|更新于2026-09-02|雀跃

快速部署自己的线上项目

    mindmap
  root((快速部署自己的线上项目))
    01：服务器与域名购买
      注意点
        服务器是必需的，域名不是
        两者都需要付费购买
        服务器购买后即可使用，域名需要备案
      服务器
        相当于一台远程电脑
        购买时分配公网 IP
          192.168.x.x 是局域网 IP
      域名
        备案后才可以使用
        建议和服务器在同一家服务商购买
        配置 DNS 解析
    02：服务器连接方案
      注意
        云服务器不能像家用电脑一样直接打开
      操作方案
        SSH 命令操作
        Xshell 或 FTP 传输文件
    03：软件安装
      Nginx
        sudo yum install nginx -y
      Node.js
        直接安装固定版本
        使用 NVM 管理版本
          下载 NVM 安装脚本
          配置环境变量
          nvm install 16
      MongoDB
        添加 MongoDB Yum 仓库
          创建 mongodb-org-4.4.repo
          写入仓库配置
        安装并启动 MongoDB
          sudo yum install -y mongodb-org
          sudo systemctl start mongod
          sudo systemctl enable mongod
          sudo systemctl status mongod
    04：项目部署
      数据库
        创建新数据库
        迁移数据
      后端代码
        上传后启动服务
      前端代码
        npm run build
        使用 Nginx 托管构建产物

公网IP就是访问电脑的方式，购买的时候赠送一个

选择经济型两核2gb的就行

镜像选择CentOS 7.6版本的就行

系统盘40G够用

数据盘和快照服务不用管

公网IP一定要选，勾选分配公网IPV4地址

带宽选1兆就行

安全组不用管

登录凭证选自定义密码，连接的时候要输入这个账号和密码。

服务器地点理论上距离越近越快

可以在阿里云，搜索域名注册，域名在使用前需要备案，但是备案并不难

域名购买成功后需要解析DNS（就是绑定服务器），主机记录，比如某网站的为www.zzz.com，这个www就是主机记录，zzz.com是购买的域名，然后记录类型如果选择A的话记录值，直接填服务器的公网IP就行了，记录值取决于记录类型。

上线准备

可以使用Xshell来传输文件到服务器，在Xshell中绑定服务器，就可以进入到服务器的终端了，我们需要在终端中下载三个软件1.Nginx 2.Node 3.数据库（MySQL/mongoDB/Redis等）

配置前端项目的时候修改里面的 nginx.conf 就行了

传输文件

使用FTP工具来传输文件到服务器，选择好服务器后，直接将本地文件夹中的文件托进去就行了

项目部署

一、数据库

我们可以使用DataGrip来连接服务器的数据库，使用SSH连接,主机就是服务器的IP，连接好后创建数据库就行了。

按SSH中的三个点，配置一下SSH连接，那个本地端口不用问。

在常规选项中配置一下服务器中的MySQl账号和密码就行了

二、后端代码

在FTP中新建一个文件夹，传入的后端代码就和GitHub上的一样，然后再服务器终端中cd 到后端代码的文件夹中，使用npm安装所有的依赖，在运行 npm run dev就可以运行后端代码了。

但是使用 npm run dev 终端就不可以执行其他的命令了，，我们可以使用 PM2 这个工具，安装pm2

使用pm2来运行项目服务的入口文件，运行成功后，大概阿里云配置安全组，设置哪些端口可以被外部访问，其中优先级随便，目的就是服务器的端口号如下图的为3004，目的就填写3004/3004，源就是授权对象，为0.0.0.0/0就是所有人都可以访问，之后就可以保存了。

此后我们就可以访问接口了，在浏览器中通过就可以访问查看后端是否是成功。

三、部署前端

（1）打包

后端项目不需要打包直接传，但是前端的代码需要打包，使用npm run bulid将前端项目进行打包，将打包的项目通过FTP传入云服务器中和后端项目同级。

（2）配置nginx

输入nginx -t可以查看nginx的配置文件nginx.conf,我们可以将云服务器中的这个nginx配置文件拖到本地中进行修改，让他能够启动对应的前端项目，修改后再拖回去就行了，如果要用https进行访问的话，需要提前准备ssl的证书文件，直接放到nginx中和nginx.conf同级。

SSL可以再阿里云/腾讯云购买的域名配置中设置，没有设置SSL就是http访问
